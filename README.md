# Text-to-Speech Converter

This is a simple text-to-speech web application built with HTML, CSS, and JavaScript.  
It lets a user type text, select a voice from the available browser voices, and play the spoken output.

## Features

- Convert typed text to speech in the browser  
- Select from available system voices  
- Responsive layout using CSS `clamp()`  
- Minimal and easy-to-use interface  
- Works on both desktop and mobile browsers  

## What I Learned From This Project

- Using the Web Speech API for speech synthesis  
- Populating and updating a `<select>` element with dynamic data  
- Triggering browser-based speech with JavaScript  
- Structuring a simple UI with Flexbox  
- Making components responsive using `clamp()` instead of media queries  
- Connecting HTML, CSS, and JavaScript in a small project

## Technologies Used

- HTML  
- CSS (Flexbox, `clamp()`)  
- JavaScript (Web Speech API)
